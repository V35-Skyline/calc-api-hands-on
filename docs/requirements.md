# 機能要件

このドキュメントは、PoC（Proof of Concept）として実装する計算APIの機能要件を定義します。

## 概要
- 2つのHTTP APIを提供する。
  - 掛け算API: `/multiply`
  - 割り算API: `/divide`
- ブラウザからURLにアクセスすることで結果がHTMLとして表示されること。
- リクエストはGETのみをサポートする。
- パラメータはクエリ文字列で受け取り、`A` と `B` の2つの整数を受け付ける。

## 入力仕様
- パラメータ名: `A`, `B`（大文字）
- 型: 整数のみ（負の整数を含む）
- 必須: `A` と `B` はどちらも必須。欠如時はエラーを返す。
- バリデーション:
  - 数値でない場合はエラー（HTTP 400）
  - 範囲は通常の32/64ビット整数値の範囲を想定するが、極端に大きい値は拒否する可能性がある（実装詳細で決定）。

## 振る舞い
- 掛け算API: 結果 = A * B
- 割り算API: 結果 = A / B（整数除算ではなく、数学的な除算を行うが、入力は整数）
- ゼロ除算: `B=0` の場合はクライアントエラーとして扱い、HTTP 400 を返す。表示は日本語のエラーメッセージを含むHTMLページとする。
- 正常系のHTTPステータス: 200
- エラー系のHTTPステータス: 400（クライアント入力エラー）、500（サーバー内部エラー）

## 出力仕様
- レスポンス形式: HTML のみ（プレーンなHTMLページ、必要最小限の構造）
- 表示内容: 計算式と結果（例: "2 × 3 = 6"、"6 ÷ 2 = 3"）および簡易のエラー文言
- 表示言語: 日本語

## テスト要件（PoCレベル）
- 正常系テスト: 乗算・除算の基本的なケース
- 異常系テスト: A/B 欠如、非数値入力、B=0

## その他
- 認証: PoCのため不要
- CORS: ブラウザで直接URLアクセスする要件のみ（AJAX利用は想定しない）
